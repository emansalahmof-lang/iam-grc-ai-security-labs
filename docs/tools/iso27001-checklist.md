# ISO/IEC 27001 Implementation Checklist

Summarised requirements of ISO/IEC 27001:2022 clauses 4–10 (not the standard's text). Annex A controls are tracked in the [Statement of Applicability](../modules/cyber-grc.md#4-statement-of-applicability-soa).

<StatusChecklist storageKey="iso27001-checklist-v1" groups={ISO27001_CHECKLIST} exportName="iso27001-checklist.csv" />

Progress = items marked **Done** ÷ items not marked **N/A**. Note that clauses 4–10 are mandatory for certification — marking a clause item N/A is rarely defensible.
